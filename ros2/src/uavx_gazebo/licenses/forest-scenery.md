# GC1 scenery sources

The static world and grass model come from [NirmanJaiswal36/uavsim, revision a09359a](https://github.com/NirmanJaiswal36/uavsim/tree/a09359a3fa62b0c887f35518f469c857443bebf5).
The project distributes its world under the [GNU Lesser General Public License, version 3](uavsim-LGPL-3.0.txt).
UAV-X changes the world name, adds its airspeed and altimeter systems, and uses local tree assets.
The grass texture derives from a MOV.AI model by Luis Pinto. The original model.config accompanies it.

The tree meshes and textures come from OpenRobotics on Gazebo Fuel.
The [Oak tree, version 7](https://fuel.gazebosim.org/1.0/openrobotics/models/Oak%20tree/7)
and [Pine Tree, version 6](https://fuel.gazebosim.org/1.0/openrobotics/models/Pine%20Tree/6)
are distributed under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
